## 🇮🇷 درباره

**DevCompass** یک کوییز کوتاه و سرگرم‌کننده است برای کسانی که می‌خواهند وارد برنامه‌نویسی شوند یا مسیر یادگیری‌شان را عوض کنند:

- **۱۰ سؤال شخصیت‌محور** دربارهٔ علایق، سبک حل مسئله و هدف شغلی
- **۸ مسیر حرفه‌ای**: فرانت‌اند، بک‌اند، فل‌استک، موبایل، بازی‌سازی، هوش مصنوعی، داده، دِواپس و امنیت
- **کارت نتیجهٔ قابل اشتراک** + **چالش دوست** (لینک مستقیم)
- **۱۰۰٪ رایگان**، بدون بک‌اند، آمادهٔ GitHub Pages
- **دوزبانه فارسی/انگلیسی** با RTL کامل

### ✨ امکانات

- موتور امتیازدهی وزنی روی پاسخ‌ها
- نوار پیشرفت + کیبورد (کلیدهای ۱ تا ۴)
- کپی یک‌کلیکی نتیجه، اشتراک تلگرام و ایکس
- **اشتراک‌گذاری بومی موبایل** (Web Share API) + **دانلود کارت PNG**
- لینک چالش (`?r=<stack>&a=...`) با رمز پاسخ‌ها + پنل **مقایسه با دوست**
- **۱۲ سؤال** + انتخاب هدف (شغلی/فریلنسری/سرگرمی/یادگیری)
- **تاریخچهٔ ۸ نتیجهٔ آخر** + **تم روشن/تیره**
- **صفحهٔ مسیرهای یادگیری** (`?s=<stack>` برای لینک مستقیم)
- **ادامهٔ کوییز** اگر وسط کار بستی
- **لینک عمیق نتیجه** (`?view=result&a=...`) — بدون کوییز باز می‌شود
- **چالش گروهی محلی** — رتبه‌بندی نتایج دوست‌ها روی همان دستگاه
- **انیمیشن نتیجه** + شمارندهٔ درصد + confetti (با احترام به reduced-motion)
- **شمارش محلی رویدادها** (بدون سرور و بدون analytics شخص‌ثالث)
- **بنر نصب PWA** وقتی مرورگر اجازه دهد
- لینک ابزارهای مرتبط (Wrapped / Promptopia / Readner)
- ذخیرهٔ آخرین نتیجه در `localStorage`
- **PWA آفلاین** (manifest + service worker)
- بهینه برای موبایل (touch targets، safe-area، RTL)
- بدون وابستگی خارجی (جز فونت Vazirmatn از Google Fonts)

### 🚀 اجرا روی GitHub Pages

1. این مخزن را بساز و فایل‌ها را بگذار روی `main`.
2. **Settings ▸ Pages** → Source: *Deploy from a branch* → Branch: `main` / `(root)`.
3. سایت: `https://mohsen-niksirat.github.io/DevCompass/`

فایل `.nojekyll` کنار `index.html` هست. همهٔ مسیرها نسبی‌اند.

## 🇬🇧 About

**DevCompass** is a short, fun quiz for people who want to start coding or change their learning path:

- **10 personality-style questions** about interests, problem-solving style and career goals
- **8 career tracks**: Frontend, Backend, Full-Stack, Mobile, Game Dev, AI, Data, DevOps, Security
- **Shareable result card** + **friend challenge** links
- **100% free**, no backend, GitHub Pages ready
- **Bilingual FA/EN** with full RTL

### 🚀 Deploy on GitHub Pages

1. Push this folder to a repo on `main`.
2. **Settings ▸ Pages** → Deploy from branch → `main` / root.
3. Open `https://<username>.github.io/<repo>/`.
